# Reactive LED 💡🎶

A smart LED system that reacts to sound and music, offering 60+ dynamic lighting animations and customizable effects.

## 🔧 Features
- **60+ unique lighting animations**  
- **Sound-reactive effects (sync with music)**  
- **Wi-Fi connectivity & remote control**  
- **Custom animation & color settings**  

## 🚀 Technologies Used
- **Programming Languages**: C++, Python  
- **Hardware**: ESP8266 / ESP32  
- **Libraries**: FastLED, WebSockets  
- **Wireless Control**: IoT-based connectivity
